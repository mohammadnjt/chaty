# Chaty 💜

پیام‌رسان با تماس صوتی و تصویری. بکند **Go** (یک فایل اجرایی) و فرانت **React + Vite**. خروجی اندروید با **Nitron** گرفته می‌شود.

## قابلیت‌ها

- **چت شبیه تلگرام:** ریپلای (با سوایپ به چپ یا دابل‌کلیک)، ویرایش (با ↑ یا از منو)، حذف برای خودم یا برای همه، فوروارد، کپی، ری‌اکشن، پین، تیک خوانده‌شدن، «در حال تایپ» و «در حال ضبط ویس».
- **فایل:** ارسال عکس، ویدیو، ویس‌مسیج و هر فایلی با کپشن و نوار پیشرفت. پیست عکس با **Ctrl+V** و درگ‌اند‌دراپ هم کار می‌کند؛ در اپ اندروید عکس و گیف از کیبورد گوشی (مثل کلیپ‌بورد Gboard).
- **اعلان (Push):** پیام جدید، تماس ورودی و تماس از دست‌رفته، حتی وقتی Chaty بسته است (در اپ اندروید، مرورگر و وب‌اپ نصب‌شده؛ در تنظیمات ← Connection خاموش و روشن می‌شود). فقط برای کسی فرستاده می‌شود که اپ جلوی چشمش نیست، و چت‌های بی‌صدا شده اعلان نمی‌دهند.
- **استوری:** عکس یا ویدیو برای ۲۴ ساعت. فقط کسانی که با شما چت مستقیم دارند می‌بینند. می‌بینید چه کسانی دیده‌اند و هر وقت بخواهید حذفش می‌کنید. ادمین می‌تواند از تب Features خاموشش کند.
- **تماس صوتی و تصویری:** میوت، خاموش کردن دوربین، تعویض دوربین، کوچک کردن تماس و تاریخچهٔ تماس‌ها.
- **تماس حتی وقتی شبکه WebRTC را می‌بندد:**
  1. اول اتصال مستقیم (P2P) امتحان می‌شود.
  2. بعد TURN داخلی روی UDP و TCP.
  3. اگر تا زمان تعیین‌شده وصل نشد، صدا و تصویر از **همان اتصال امن وب‌سوکت سرور** رد می‌شود. این کار خودکار است و در صفحهٔ تماس برچسب «via server» نشان داده می‌شود.
- **ورود با شماره موبایل و رمز.** حساب جدید تا **تأیید ادمین** فعال نمی‌شود.
- **پیدا کردن افراد:** هیچ‌کس لیست کاربران را نمی‌بیند. کاربر جدید فقط با **شمارهٔ کامل** یا **آیدی دقیق** (مثل `@reza_k`) پیدا می‌شود؛ هم در «چت جدید» و هم در جستجوی صفحهٔ چت‌ها. بدون جستجو فقط مخاطب‌های خودتان و **حساب ادمین** دیده می‌شوند (همه می‌توانند به ادمین پیام بدهند).
- **ادمین** هر کاربری را با بخشی از شماره، اسم یا آیدی پیدا می‌کند و شمارهٔ کامل را می‌بیند.
- **آیدی:** هر کاربر در تنظیمات یک آیدی یکتا برای خودش می‌گذارد.
- **بلاک:** از پروفایل داخل چت. کاربر بلاک‌شده نمی‌تواند پیام بدهد یا تماس بگیرد، وضعیت آنلاین، آخرین بازدید، عکس پروفایل و بیوی شما را نمی‌بیند و نمی‌تواند شما را به گروه اضافه کند. لیست بلاک‌شده‌ها در تنظیمات ← Privacy است.
- **حریم خصوصی:** «با شماره پیدایم کنند» (اگر خاموش باشد فقط با آیدی پیدا می‌شوید) و «آخرین بازدید و آنلاین بودنم دیده شود».
- **مدیریت چت:** بی‌صدا کردن اعلان‌ها، حذف چت (فقط برای خودتان؛ با پیام جدید برمی‌گردد)، پاک کردن تاریخچهٔ گروه و ترک گروه.
- **پنل ادمین** (تنظیمات ← Admin panel):
  - تأیید، رد یا مسدود کردن کاربر، ادمین کردن و عوض کردن رمز
  - روشن و خاموش کردن هر قابلیت
  - حالت تماس، TURN و STUN
  - انتخاب ذخیره‌سازی و انتقال دیتابیس
  - نام اپ و حداکثر حجم آپلود

## آدرس‌ها

| آدرس | محتوا |
|---|---|
| `/` | صفحهٔ معرفی (لندینگ) با دکمه‌های «Open Web App» و «Download for Android» |
| `/app/` | خود اپ تحت وب. روی گوشی و کامپیوتر به‌صورت **PWA** نصب می‌شود (Install app یا Add to Home Screen) و بدون اینترنت هم باز می‌شود. |
| `/download/chaty.apk` | آخرین نسخهٔ اپ اندروید که ادمین آپلود کرده |

## پیش‌نیازها

- Go 1.22+ و Node 20+
- برای ساخت APK: JDK (۱۱ یا بالاتر)، Python 3 و فایل `google-services.json`. اندروید استودیو لازم نیست.

## اجرا (توسعه)

```sh
npm run setup   # فقط بار اول
npm run dev     # سرور Go روی :8080 و Vite روی :5177
```

بعد `http://localhost:5177` را باز کنید.

**ورود ادمین:** شماره و رمز داخل `server/.env` است (`ADMIN_PHONE` و `ADMIN_PASSWORD`). حساب ادمین در هر بار اجرای سرور ساخته یا به‌روز می‌شود.

> مرورگر میکروفون و دوربین را فقط روی `localhost` یا HTTPS می‌دهد. برای تست تماس بین دو گوشی روی یک شبکه:
>
> ```sh
> npm run start:https
> ```
>
> بعد `https://IP-کامپیوتر:8080` را باز کنید و هشدار گواهی را یک بار قبول کنید.

## اجرا (پروداکشن)

```sh
npm start    # بیلد وب و سرور، بعد اجرا روی :8080
```

سرور Go خودش فایل‌های وب را سرو می‌کند. برای HTTPS خودکار (Let's Encrypt) در `server/.env` بنویسید:

```
DOMAIN=chat.example.com
```

پورت‌های 80 و 443 باید باز باشند. برای TURN، پورت 3478 (UDP و TCP) و بازهٔ UDP 49160-49200 را باز کنید و TURN را از پنل ادمین روشن کنید.

## اجرا روی BAS

پروژه برای [BAS](https://github.com/mohammadnjt/bas) آماده است. فایل [bas.config.json](bas.config.json) به BAS می‌گوید چطور بیلد و اجرا کند:

```json
{
  "name": "Chaty",
  "type": "backend",
  "port": 5177,
  "build": "npm run build",
  "start": "cd server && ./chaty"
}
```

**پیش‌نیاز سرور (یک‌بار):** Node و Go نسخهٔ ۱.۲۱ یا بالاتر.

**نصب:**

```sh
cd /path/to/bas/apps
git clone https://github.com/mohammadnjt/chaty.git chaty
cp chaty/server/.env.example chaty/server/.env   # بعد ADMIN_PASSWORD را عوض کنید
```

BAS ظرف چند ثانیه پروژه را پیدا می‌کند، بیلد و اجرا می‌کند. آدرس اپ `http://IP-سرور:5177` است.

**چند نکته:**

- **آپدیت:** در BAS گروه `chaty` را آپدیت کنید. خودش `git pull` می‌کند، بیلد می‌گیرد و ری‌استارت می‌کند.
- **داده‌ها:** در `chaty/files` هستند و `git pull` به آن‌ها دست نمی‌زند. از همین پوشه بکاپ بگیرید.
- **دانلود ماژول‌های Go:** در `bas.config.json` مقدار `GOPROXY` روی `goproxy.cn` تنظیم شده، برای سرورهایی که به `proxy.golang.org` دسترسی ندارند.
- **فایل `server/.env`:** در آن `PORT` یا `DOMAIN` نگذارید. پورت را BAS می‌دهد.

**HTTPS** (لازم برای تماس و اپ اندروید): پشت nginx با گواهی:

```nginx
server {
    server_name chat.example.com;
    client_max_body_size 60m;
    location / {
        proxy_pass http://127.0.0.1:5177;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 3600s;
    }
    # گواهی: certbot --nginx -d chat.example.com
}
```

## اعلان‌ها (Firebase)

اعلان‌ها از Firebase Cloud Messaging فرستاده می‌شوند.

1. در کنسول Firebase، بخش Project settings ← Service accounts، یک کلید خصوصی بسازید (فایل JSON).
2. آن را با نام `firebase-service-account.json` در پوشهٔ داده‌ها (`files/`) بگذارید و سرور را ری‌استارت کنید. در لاگ باید `push: Firebase project ...` بیاید. (یا مسیرش را در `FIREBASE_CREDENTIALS` بدهید.)
3. تنظیمات وب Firebase و کلید VAPID در [app/src/lib/push.ts](app/src/lib/push.ts) هستند.

این فایل کلید خصوصی است: هیچ‌وقت در گیت نگذارید (الگوی `*firebase-adminsdk*.json` در `.gitignore` هست).

## ساخت APK

```sh
echo "VITE_SERVER_URL=https://chat.example.com" > app/.env.production   # اختیاری
npm run apk     # بیلد وب، Nitron و بعد بخش نیتیو Chaty → app/dist/app.apk
```

- آدرس سرور از فایل [app/.env.apk](app/.env.apk) داخل APK قرار می‌گیرد، پس اپ بعد از نصب خودکار وصل می‌شود.
- **انتشار:** در پنل ادمین، تب General، بخش «Android app»، فایل `app/dist/app.apk` را با شمارهٔ نسخه آپلود کنید. لینک دانلود در صفحهٔ لندینگ به‌روز می‌شود.
- اپ اندروید **فقط به سرور HTTPS** وصل می‌شود، چون WebView درخواست‌های http را مسدود می‌کند.
- اگر `VITE_SERVER_URL` را ندهید، اپ در صفحهٔ ورود آدرس سرور را می‌پرسد.
- مجوزهای دوربین، میکروفون، بلوتوث و نوتیفیکیشن در `app/nitron.config.json` تنظیم شده‌اند. با هر نسخهٔ جدید، `version` همین فایل را بالا ببرید.
- **بخش نیتیو اندروید** ([app/android/](app/android/)): Nitron فقط وب‌اپ و آیکون را می‌دهد؛ [build_apk.py](app/android/build_apk.py) بقیه را می‌سازد: اکتیویتی خودِ Chaty (صدای تماس با بلندگو/گوشی/هندزفری سیمی و بلوتوثی، انتخاب عکس و ویدیو و فایل، عکس از کیبورد، باز شدن لینک‌ها در مرورگر) و **اعلان‌های Firebase** (پیام، تماس ورودی روی صفحهٔ قفل، تماس از دست‌رفته). کتابخانه‌های Firebase را خودش از Maven دانلود می‌کند (از میرور Aliyun که از ایران باز است) و در `app/android/.tools` نگه می‌دارد؛ بار اول چند دقیقه طول می‌کشد.
- **`google-services.json`:** از کنسول Firebase (اپ اندروید `app.chaty.messenger`) در ریشهٔ پروژه. در گیت نیست.
- **کلید امضا:** `npm run apk` با کلید اختصاصی Chaty امضا می‌کند: `app/android/release.keystore` و رمزش در `app/android/keystore.properties`. این دو فایل عمداً در گیت نیستند. **از هر دو نسخهٔ پشتیبان جای امن نگه دارید:** بدون همین کلید هیچ نسخهٔ جدیدی روی اپ نصب‌شده نصب نمی‌شود و همه باید اپ را پاک و دوباره نصب کنند. اگر این فایل‌ها نباشند، APK با کلید عمومی Nitron امضا می‌شود و هشدار می‌دهد.
  - ساخت کلید برای پروژهٔ تازه: `keytool -genkeypair -keystore app/android/release.keystore -storetype PKCS12 -alias chaty -keyalg RSA -keysize 4096 -validity 12000` و بعد `keystore.properties` را مثل همین پروژه بسازید (`storeFile`، `storePassword`، `keyAlias`، `keyPassword`).

## ذخیره‌سازی (پوشهٔ `files/`)

همه‌چیز در پوشهٔ `files/` کنار پروژه است:

| مسیر | محتوا |
|---|---|
| `files/data/chaty.jsonl` | داده‌ها (پیش‌فرض) |
| `files/uploads/` | فایل‌ها و عکس‌های آپلودشده |
| `files/settings.json` | تنظیمات پنل ادمین |

پیش‌فرض یک فایل **JSON Lines** است:

- هر تغییر فقط به انتهای فایل اضافه می‌شود. کرش یا قطع برق داده‌های قبلی را خراب نمی‌کند و خط نیمه‌کاره هنگام بارگذاری نادیده گرفته می‌شود.
- فایل خودکار فشرده (compact) می‌شود.

از پنل ادمین (تب Storage) می‌توانید آدرس یک دیتابیس بدهید:

- PostgreSQL: `postgres://user:pass@host:5432/chaty`
- MySQL: `mysql://user:pass@host:3306/chaty`
- یا یک فایل SQLite

اول **Test connection** را بزنید، بعد **Switch & copy data**. همهٔ داده‌ها خودکار به دیتابیس جدید کپی می‌شوند. برگشت به فایل هم همین‌طور است.

اگر دیتابیس در دسترس نبود و سرور بالا نیامد، در `server/.env` بنویسید `STORAGE_DRIVER=file`.

## ساختار پروژه

```
server/   بکند Go
  main.go       تنظیمات، HTTPS، راه‌اندازی
  api.go        REST API (پیام، فایل، ریپلای، ری‌اکشن، …)
  admin.go      API پنل ادمین
  hub.go        وب‌سوکت، حضور آنلاین، رلهٔ صدا و تصویر تماس
  calls.go      سیگنالینگ تماس
  store.go      مدل داده در حافظه
  persist.go    ذخیره‌سازی (JSONL / SQLite / PostgreSQL / MySQL)
  settings.go   تنظیمات قابل تغییر از پنل
  net.go        TURN داخلی و گواهی self-signed
app/      فرانت React + Vite (و nitron.config.json)
  android/      بخش نیتیو اندروید (جاوا) و build_apk.py که APK را می‌سازد
  src/call/     موتور تماس (WebRTC + رلهٔ سرور)
  src/screens/  صفحه‌ها (چت‌ها، چت، تماس‌ها، استاتوس، تنظیمات، ادمین)
files/    داده‌ها و آپلودها
```
